## 🌟 What is in this repository

This project contains two primary applications:

### 1. Web Application (`website/`)
A responsive anime streaming web application designed for desktop and mobile browsers:
- Responsive interface with mobile bottom navigation, search drawer, and cinema player stage.
- Instant dual audio switching (**SUB** Japanese / **DUB** English).
- Subtitle rendering and automatic text formatting.
- Multi-resolution stream quality selector.
- Synchronized watch progress and watchlist bookmarks.

### 2. Android TV App (`tv-app/`)
A native Android TV application built with Jetpack Compose for TV and ExoPlayer:
- Tailored for TV remotes and D-Pad navigation.
- Continue watching rail with watched progress tracking.
- Cinema video player with resolution selection and audio controls.
